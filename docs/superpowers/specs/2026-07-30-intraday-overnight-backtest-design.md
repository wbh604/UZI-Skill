# A股尾盘隔夜策略与分钟数据归档设计

## 目标

在不暴露凭据、不重复采集成功分片、不中断当前周卡归档的前提下，利用
Tushare 兼容数据源建立近三年 A 股 1 分钟行情归档，并实现一个无未来函数、
无当前成分股幸存者偏差、包含真实交易约束的尾盘隔夜策略回测器。

首轮研究只验证一个预先定义的信号：

```text
14:00–14:19 个股收益率 − 同时段沪深300收益率
```

每日从点时合格股票池中选择得分最高的一只。14:20 生成信号，
14:30–14:34 分五笔买入，次日 9:35–9:39 分五笔卖出。系统只生成研究结果
和候选单，不连接券商，不自动下单。

## 范围

### 包含

- 探测历史股票分钟接口的权限、字段、时间标签、行数上限和日期归属。
- 从已有日线归档构建逐交易日的点时流动性前 500 股票池。
- 拉取三年内曾进入点时前 500 股票池的证券并集的 1 分钟行情。
- 保存原始响应、标准化分钟数据、哈希、来源、抓取时间和 manifest 状态。
- 根据每日复权因子生成仅供信号计算使用的复权分钟价格。
- 使用未复权真实价格模拟成交。
- 处理停牌、ST、涨跌停、上市、退市、除权除息和无法成交。
- 同时产出不受本金限制的信号检验结果和 1 万元账户约束结果。
- 训练、验证、冻结测试、按交易日 block bootstrap 和参数敏感性分析。

### 不包含

- 自动下单、券商账户控制或持仓同步。
- L2 委托簿、逐笔成交、集合竞价订单队列复现。
- 首轮同时测试多个技术因子。
- 在首轮信号无效时自动搜索大量参数或挑选最优因子。
- 在分钟数据接口未通过探测时伪造或用日线替代分钟回测。
- 修改现有选股评分、报告管线或无关未提交工作。

## 执行顺序与在线采集约束

当前 `export_tushare_mainbz.py` 以 120 次/分钟运行时，不启动任何分钟接口请求。
只有在现有在线采集进程退出后，才执行一分钟权限探测。

探测和归档遵守：

- 固定 120 次/分钟；
- 最多 12 个 worker；
- 所有 worker 共享一个请求启动限流器；
- append-only manifest；
- 成功分片不重复请求；
- 429、502、超时保留失败记录并在当前轮结束后重试；
- Token 只从现有环境加载器读取，不写入命令行、日志、manifest 或数据文件。

若 `stk_mins` 不支持、权限不足或只提供当日数据：

1. 将探测结果记录为 `unsupported` 或 `realtime_only`；
2. 不启动全量分钟归档；
3. 保留回测引擎和测试夹具；
4. 使用 `rt_min_daily` 仅建立后续模拟盘日增量，历史回测保持 blocked；
5. 不把其他来源的日线数据冒充分钟数据。

## 点时股票池

### 来源全集

来源全集包含在研究期间曾上市的全部 A 股，包括后来退市、曾被 ST、曾停牌的证券。
不得用当前上市列表回填历史。

### 每日资格

在交易日 `T` 的 14:20，只使用 `T` 当时已经可得的信息。证券需同时满足：

- `list_date <= T - 60` 个自然日；
- `T` 日 14:20 前存在有效分钟成交；
- `T` 日当时不是 ST 或退市整理状态；
- `T` 日当时未停牌；
- 过去 20 个已完成交易日日均成交额有效；
- 14:20 前的数据字段完整，能够计算首轮信号。

ST、名称变更、停复牌和退市状态必须按生效日期映射，不能用当前名称推断历史状态。
涨停是否可成交不在股票池阶段预判，而由 14:30–14:34 的执行器依据当时分钟数据
逐笔判定，避免用 14:20 后的信息筛选候选。

### 流动性排名

对每日合格证券，按 `T-20` 至 `T-1` 的 20 个完整交易日日均成交额降序排列，
选择前 500。`T` 当日尚未收盘的成交额不进入排名。

分钟归档目标证券是研究区间内每日前 500 股票池的并集，而不是当前前 500。
首轮完成后若时间与容量允许，可将同样规则扩展至每日前 1000。

## 分钟数据契约

标准化记录至少包含：

```text
ts_code
bar_start
bar_end
open
high
low
close
volume_shares
amount_yuan
trade_date
source
fetched_at
```

约束：

- 时区固定为 `Asia/Shanghai`；
- `bar_start`、`bar_end` 必须明确，不能只保存含义不明的 `time`；
- 价格和金额为有限正数；
- 成交量和成交额非负；
- 同一 `(ts_code, bar_start)` 唯一；
- 每条记录只能属于请求的证券和月份；
- 上午、下午交易时段之外的数据拒绝入库；
- 停牌整日允许合法空分片，但必须由交易状态数据支持；
- 接口返回达到行数上限时，该分片必须继续细分，不能接受为完整结果。

### 时间标签探测

权限探测必须用一个有成交的完整交易日验证：

- 首根记录对应 9:30–9:30:59 还是前一分钟；
- 14:19 标签的记录何时完整；
- 午间是否产生伪分钟；
- `vol` 是股、手还是百股；
- `amount` 是元、千元还是其他单位。

探测结论写入 `minute_probe_results.json`。时间标签语义未确定时，归档和回测均阻断。

### 分片与文件

- API 请求优先按证券和自然月分片；
- 若自然月超过接口行数上限，则按半月或交易日继续拆分；
- raw：`raw/stk_mins_1m/<ts_code>/<shard>.jsonl.gz`；
- normalized：`normalized/stk_mins_1m/<ts_code>/<shard>.parquet`；
- manifest 主键：`(dataset="stk_mins_1m", shard_id="<code>__<period>")`。

每个成功分片记录行数、日期边界、raw/normalized SHA256、数据源和抓取时间。

## 复权与价格口径

执行成交使用分钟接口返回的未复权真实价格。

跨日信号和历史收益特征使用每日 `adj_factor` 映射到对应交易日：

```text
adjusted_minute_price = raw_minute_price × normalized_adj_factor
```

`normalized_adj_factor` 只需在同一证券历史内保持连续，不用于生成下单价格。
发生拆分、分红或除权时，必须通过测试验证信号价格连续、成交价格保持真实。

## 信号

首轮只实现一个参数最少的相对尾盘动量信号：

```text
stock_return = close_14_19 / close_13_59 - 1
benchmark_return = benchmark_close_14_19 / benchmark_close_13_59 - 1
score = stock_return - benchmark_return
```

规则：

- 14:20:00 运行时只读取 `bar_end <= 14:19:59` 的记录；
- 每日按 `score` 降序排列；
- 最多选择一只；
- 分数相同按 `ts_code` 排序，保证结果确定；
- 不增加固定涨幅阈值、成交量阈值或其他技术指标；
- 若当日没有可执行候选，允许空仓，不强制交易。

沪深300分钟基准优先使用历史指数分钟接口。若指数分钟接口不支持，使用对应交易日
点时有效的沪深300历史成分股分钟收益构造代理前，必须单独验证并记录误差；不得用
当前成分股回填历史，也不得用收盘后日线替代。

## 执行模拟

### 买入

- 窗口：14:30、14:31、14:32、14:33、14:34 五个完整分钟；
- 目标数量按 100 股向下取整；
- 每分钟目标为剩余初始目标数量的五分之一，并按 100 股修正；
- 每分钟成交量参与率不超过 5%；
- 基准成交价为 `amount_yuan / volume_shares`；
- 成交价为 `VWAP × (1 + slippage_bps / 10000)`；
- 默认输出 5、10、20 bps 三档，20 bps 是压力结果；
- 未成交数量在同一窗口后续分钟继续尝试，14:34 后取消；
- 无成交额、无成交量、封涨停或状态不明时不假设成交。

### 卖出

- 窗口：下一可交易日 9:35–9:39；
- 成交价为 `VWAP × (1 - slippage_bps / 10000)`；
- 同样遵守 5% 成交量参与率；
- 封跌停、停牌或状态不明时不假设成交；
- 未成交持仓继续占用资金，并在下一交易日同一窗口重试；
- 每个持仓设置最大模拟持有日仅作为风险报告字段，不允许到期后凭空成交。

### 价格限制

仅有一分钟 OHLCV 时无法复现委托队列。模型采用保守规则：

- 买入窗口分钟收盘价等于涨停价时，该分钟不可买；
- 卖出窗口分钟收盘价等于跌停价时，该分钟不可卖；
- 该假设必须在结果中列为保守执行限制；
- 若未来取得 L2，再以独立执行器替换，不修改信号。

## 费用

股票账户默认参数可由 CLI 覆盖：

```text
commission_rate = 0.00025
minimum_commission = 5.00 CNY per order
sell_stamp_tax = 0.0005
transfer_and_regulatory_fee = configurable
```

每个实际成交订单分别计算最低佣金。卖出印花税只在卖出成交额上计算。
所有费用以现金扣除，资金不足时减少目标股数，不允许负现金。

## 两套组合结果

### 信号经济性

- 每日选择一只；
- 使用统一名义金额；
- 评估信号本身扣除比例费用和滑点后的收益；
- 不将其描述为用户可直接获得的账户收益。

### 1万元账户

- 初始现金 10,000 元；
- 每日最多一个新持仓；
- 100 股整数交易；
- 默认单笔目标资金为可用现金和 5,000 元中的较小值；
- 已有延期持仓时，剩余现金不足则跳过新信号；
- 逐笔收取最低佣金；
- 输出现金占用、未成交、错失信号和实际持仓天数。

该 5,000 元仅是研究账户默认值，实盘试验资金上限另行决定，不由回测器自动建议。

## 数据切割和验证

按交易日排序后：

- 前 60%：训练区，仅用于验证数据和实现，不搜索大量参数；
- 中间 20%：验证区，用于冻结数据清洗和执行参数；
- 最后 20%：测试区，参数冻结后只运行一次。

若测试区失败，结果记为失败。修改策略后必须创建新的实验版本和新的未见测试区，
不能覆盖原实验。

### 统计单位

同日多证券结果相关，因此统计以每日账户净收益为单位。置信区间使用按连续交易日块
抽样的 block bootstrap，不对单笔交易独立重采样。

### 必须报告

- 毛收益、净收益、全部费用和滑点损耗；
- 每日净期望及 block bootstrap 95% 置信区间；
- Profit Factor；
- 最大回撤、最差单日和 5% 尾部损失；
- 交易日数、信号数、成交数、未成交数；
- 胜率、平均盈利、平均亏损、最大连续亏损；
- 资金利用率、平均持有日、延期卖出次数；
- 5/10/20 bps 三档结果；
- 1万元账户与统一名义账户的差异。

### 市场状态

沪深300状态只使用 `T-1` 以前的数据：

- 趋势：收盘相对 200 日均线；
- 波动：20 日已实现波动率相对截至 `T-1` 的扩展历史 40% 分位。

四个状态分别报告日均收益、Profit Factor、5% 尾部损失和连续状态区间回撤。
不把非连续状态日期拼接后计算回撤。

## 模拟盘

历史测试通过后才启动模拟盘：

- 每个交易日 14:20 生成候选；
- 保存输入数据截止时间、候选、得分、拒绝原因和模拟订单；
- 使用真实后续行情评估成交；
- 至少运行 60 个交易日；
- 至少累计 200 个有效信号；不足 200 时延长，不强行进入实盘；
- 模拟盘结果与历史测试使用同一费用和执行器。

## 错误处理

- 权限拒绝：记录 unsupported，停止该接口；
- 参数错误：记录探测失败，不启动全量；
- 行数封顶：细分分片；
- 返回其他证券或其他月份：拒绝分片；
- 时间标签不明：阻断归档；
- 重复主键：拒绝分片；
- 429、502、超时：记录失败并重试，不删除成功文件；
- 单个证券失败：不阻断其他证券；
- 质量门禁失败：该分片不进入回测。

## 测试与完成条件

所有生产行为先有失败测试，再写最小实现。至少验证：

- 14:20 信号看不到 14:20 分钟；
- 流动性排名只使用 `T-1` 以前的完整日线；
- 当前上市列表不会排除历史退市股票；
- ST、停牌状态按生效日期使用；
- 买入加滑点、卖出减滑点；
- 最低佣金按实际订单逐笔收取；
- 100 股取整和资金不足；
- 涨停不买、跌停不卖、停牌延期；
- 复权信号连续而成交价格未复权；
- 同日结果按交易日 block bootstrap；
- manifest 恢复不重复请求；
- 满行响应继续拆分；
- Token 不出现在命令、日志和 manifest。

完成定义：

1. 分钟接口探测结论可审计；
2. 支持时，三年目标证券分片完成或明确列出失败；
3. 所有归档分片通过运行时质量门禁；
4. 回测测试区只运行一次并保存实验版本；
5. 输出两套组合结果和全部必报指标；
6. 所有新增测试及相关归档回归测试通过；
7. 无券商连接和自动下单能力。
