# 行业资金流轮动

入口：仓库根目录 `rotate.py`。这是独立的 A 股行业研究工具，不改变 `run.py` 个股分析或 `screen.py` 游资日筛的评分、消息验证和成交条件。

## 运行

仅使用 Python 3.10+ 标准库，无新增依赖。准备有权使用的行业主动买卖额本地 CSV，工具不绑定特定数据商：

```bash
python3 rotate.py --input-csv /path/to/citic_industry_fund_flow.csv --as-of 2026-11-04

# 可选：附上符合下述契约的本地代理观察，仍与正式数据隔离
python3 rotate.py --input-csv /path/to/citic_industry_fund_flow.csv \
  --as-of 2026-11-04 --proxy-json /path/to/today_proxy_2026-11-04.json
```

日期是格式示例，不代表随包提供该日数据。工具不联网采集、不包含账号、Token、真实数据或自动交易能力；也不会把旧文件标成今天的数据。可用 `--output-dir` 指定本地结果目录。未接入免费替代数据源；没有符合契约的合规输入时，应停止而不是用价格代理冒充主动买卖额。

默认输出 `skills/deep-analysis/scripts/reports/rotation/<截止日>/`：

- `report.html`：本地直接打开，切换 W=20–24；正式40行业排名、前日变化、共同入选行业、周频模型目标和独立代理观察。
- `rotation.json`：完整结构化结果、实际数据日期、自然日滞后、来源文件名与 SHA256。
- `rankings.csv`：正式与代理分别标记 `layer`，不能按行业名称直接拼接或混排。

同目录重跑会更新这三个结果文件；需要保留多个版本时指定不同目录。仅导入代理快照不够，正式 CSV 为必需项。

## 数据契约

CSV 每行是某交易日的一个中信二级行业；UTF-8 或 UTF-8 BOM。必需字段：

| 字段 | 含义 |
|---|---|
| `date` | 交易日期，YYYY-MM-DD；仅含已经完整收盘的日数据 |
| `l1_code`, `l1_name` | 中信一级行业代码、名称 |
| `l2_code`, `l2_name` | 中信二级行业代码、名称；同日期代码不可重复 |
| `active_buy_amount`, `active_sell_amount` | 主动买入额、主动卖出额；非负、相同货币与单位 |
| `turnover_amount` | 成交额；正数，与主动买卖额同单位 |
| `float_market_cap` | 流通市值；正数，所有行业单位一致 |
| `industry_return` | 日收益小数，例如 1% 写作 `0.01`，不是 `1` |

至少25个完整交易日，建议提供40个以上，以覆盖所有窗口、前日变化和已完成周信号。40行业映射定义在 `lib/industry_rotation/core.py` 的 `INDUSTRIES`：部分一级行业聚合全部二级行业，指定板块按二级行业拆分。聚合收益使用期初流通市值权重：`期初市值 = 当日市值 / (1 + 日收益)`。

缺字段、非有限值、非法金额/收益、重复日期行业、已出现日期缺少40行业之一时停止计算，不填零、不静默删日。输入未包含的整个交易日、一级行业少报部分二级成分，单靠该 CSV 无法完全发现，数据提供者必须保证覆盖完整。当前不连接交易所日历。

## 计算方式

研究方法参考华泰证券《行业资金流向图应用于行业轮动》（2026-08-13）；未复制或分发研报正文和商业数据。

对每个行业 i、每个交易日：

```text
q_i = 主动买入额_i / 全行业主动买入额 - 主动卖出额_i / 全行业主动卖出额
v_i = 成交额_i / 全行业成交额
s_i = 流通市值_i / 全行业流通市值
基础原始因子 = q_i / v_i
```

资金图增加一个市场外部节点，以日超额收益、`v_i`、`s_i` 拟合反对称边流，同时保持节点净流守恒。使用固定18轮、确定性的近似求解器，并非原研报未披露的多初值优化器。

五个因子依次为：基础原始因子、最大行业边流/成交占比、正行业边流数量占比、负行业边流合计/成交占比、外部节点边流/成交占比。先分别做 W 日算术平均，再做每日行业截面 z-score；综合分取五个标准分的均值。截面零方差时标准分为0。W=20–24全部展示，不根据历史收益自动挑选最优窗口；排名分数不是上涨概率。

## 周频与临时观察

每周最后一个数据交易日收盘形成信号，下一周首个数据交易日收盘按 Top 5 等权形成模型目标，新组合收益只能从随后交易日起计。工具只在已观察到跨周边界后确认周信号，最后一个尚未确认的周末不提前生成调仓。周内滚动排名变化不覆盖上一周的目标。报告不追踪实际持仓、权重漂移或交易。

临时 JSON 使用中性的 `status: public_proxy_observation` 契约：必含 `as_of` 及 `windows` 下20–24五个窗口，每个窗口有 `base`、`composite` 各5条降序记录，每条含 `rank/code/name/score`。任何缺窗、重复代码、非法分数或晚于研究截止日的快照都拒绝导入。旧命令参数和旧数据商专属格式不再保留兼容入口；已有本地文件保持原样。

**申万30临时排名的原算法使用 Money Flow Multiplier × 成交额代理资金流、60日平均成交额代理规模，不是直接使用当天东方财富主力净流入榜。** 本工具导入其已算好的排名，不重新采集或重算该代理模型；数据真实性和源端算法执行情况须在源项目核验。源文件的资金榜涉及不同层级板块，可能重叠，不在本工具内相加或当作同级行业截面。

中信40正式排名与申万30临时排名不可直接比较名次，不能互相补历史、替代正式持仓，也不应把临时前三行业冒充正式模型的共同核心。

```bash

```

测试仅使用运行时构造的合成数据，覆盖因子公式、零方差、守恒、聚合、非法输入、历史截止、周频延迟、代理隔离、HTML转义、CLI产物和数据防误提交。工程检查不证明收益、因果关系或有效交易能力；公开文档不附真实排名、数据截图或源文件。

`--as-of` 过滤交易日期，不知道原始数据的信息发布日期或历史修订记录；不是完整点时回测系统。本次不复制原回测收益、不宣称复现研报业绩，也没有提供港股/美股同策略、ETF映射、组合回测或自动定时任务。输出始终 `observation_only`，用于行业研究和后续个股分析的背景，不放宽原有风控条件。
